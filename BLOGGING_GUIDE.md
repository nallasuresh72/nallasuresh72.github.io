# How I will publish SAP BASIS blogs

## For now

The website has no sample/fake blog posts. The Blog section will show "Blog coming soon" until real posts are added.

## Recommended workflow

1. Decide the topic.
2. Draft the article in ChatGPT or a text/Markdown editor.
3. Create a blog post file in a `blogs` folder.
4. Add the article title/category/date/description to `data/site-data.js`.
5. Commit the changes to GitHub.
6. GitHub Pages automatically republishes the site when the `main` branch changes.

## Important

Do not publish confidential client information, customer names, system names, hostnames, IP addresses, screenshots containing sensitive data, credentials, tickets, or internal procedures.

## Future improvement

I recommend that we convert the current Blog section into a proper article system where each post has its own URL, for example:

`/blog/sap-sum-upgrade-guide.html`
